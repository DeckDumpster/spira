# §1.330 law-run-it-once-before-you-decompose

Before decomposing work whose premise is that something is broken, run the thing once and read the result. A decomposition inherits its premise untested, and every bead then buys a session to fix what may need no fixing. If the premise cannot be measured yet, cut the bead that measures it first. Scar: 220 per-suite beads catalogued what each suite needed in a container, hours after a third run in a row produced zero results — none had ever run in one.
