# §1.559 sop-unclaimable-missing-scope-label

MATCH: external_ref contains unclaimable: and description mentions missing scope label
SYMPTOM: A ready bead is unclaimable because it lacks the required scope label (spira)
CHECK: Aeons have no bd and `work show <other-bead>` is refused (not the bound bead), so an aeon CANNOT run the check. Record --check fail --held unknown, then escalate; do not retry. (Operator session: bd -C $SPIRA_DB show <bead-id> --format json | jq '.[] | .labels | contains(["spira"])')
FIX: Operator/non-aeon session only: bd -C $SPIRA_DB label add <bead-id> spira. If the target recurs within a day it is likely deliberately unlabelled: retire it instead of relabelling.
ESCALATE: Always from an aeon context: ask the operator to label or retire the named bead. Also if bead type is not task/incident, verify first; a decision bead with no scope label may be misfiled.
