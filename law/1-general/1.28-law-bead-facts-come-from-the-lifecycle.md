# §1.28 law-bead-facts-come-from-the-lifecycle

Every fact about work has one owner and is read from it through spira-lc, never copied into the other plane. The planning plane, bd through the planning verbs, owns the bead: title, body, labels, priority, type, comments, dependency and parent edges, epic membership. The control plane, the state store through the state verbs, owns each work bead's lifecycle record (state, tip, holder, holds, and repo, set once at create), readiness, rounds, verdicts, sections, intents, locks and ask state; bd status for a work bead is written only from its lifecycle record. The planes join only by bead id. A missing fact is added to its owner, never read around it. Scar: a round pool read repo labels through a bd passthrough (sp-kns3d5).
