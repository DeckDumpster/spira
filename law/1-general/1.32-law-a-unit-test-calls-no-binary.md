# §1.32 law-a-unit-test-calls-no-binary

A unit test exercises library code in its own process and never spawns another binary, script or tool; one that must is a strongly justified exception, written beside it. Every test binary runs sandboxed, so none can reach a live install. A test that spawns binaries is slow and couples itself to whatever the environment resolves. Scar: 2026-11-02, a host test run reached the live mailbox through a spawned mail binary, and the unit tier took 7 minutes, mostly in tests that spawned processes (sp-ao9dn2, sp-bpenvh).
