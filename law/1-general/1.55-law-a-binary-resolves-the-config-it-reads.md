# §1.55 law-a-binary-resolves-the-config-it-reads

A binary or shim that needs configuration conf.sh resolves must resolve it itself, in-process through spira-config, never read it from its own environment: almost nothing conf.sh resolves is exported, and a unit starts a binary with only SPIRA_RELEASE and PATH. A test that exports the variable hides the bug, so test with it set but unexported. Scar: the persona roster went empty and queue, sending and landing-pass lost every landing ref, three times in one day (sp-nki5w, sp-z3eyk).
