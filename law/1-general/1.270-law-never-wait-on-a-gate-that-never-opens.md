# §1.270 law-never-wait-on-a-gate-that-never-opens

Never gate an action on a precondition you neither control nor can predict — an idle aeon pool, a quiet queue, a finished run. If the risk is real, measure it and make the action safe: restart only what changed, drain the one unit you are replacing, or carry a priority channel that pre-empts. A wait for a condition that never arrives is not caution, it is a decision not to act, and it hides as prudence. Auron sat uninstalled while a session waited for a pool that is never idle; the reload it feared killed nothing. (Ryan, 2026-09-08, sp-p2nm)
