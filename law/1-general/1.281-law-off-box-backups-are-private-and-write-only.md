# §1.281 law-off-box-backups-are-private-and-write-only

Every off-box backup of Spira's stores goes to a private bucket the operator owns, written with a key that can only upload: the writer can add a snapshot but never read, list, overwrite or delete one, so a compromised or buggy writer cannot destroy history; the bucket is versioned, encrypted and blocks public access, and restore uses the operator's own identity. A sync protocol that must read its remote is replaced by a local consistent snapshot uploaded as one object. Scar: the lifecycle store had no backup at all.
