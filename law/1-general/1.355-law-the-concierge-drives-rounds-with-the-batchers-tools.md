# §1.355 law-the-concierge-drives-rounds-with-the-batchers-tools

The Concierge and the batcher cut, certify, eject and land a round through the same sanctioned tools, which record the round as a batch on the lifecycle machine. The only difference between them is judgement, never tool access. If the Concierge needs to act where the batcher has no verb, that is a missing verb: build it, and the batcher uses it too. Hand-cut rounds that never ran spira-lc cut left loom and round-duty blind for a night: members looked idle in SUBMITTED for hours, and round-duty paged 'no round running' mid-certification.
