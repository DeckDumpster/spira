# §1.240 law-guard-proved-where-the-offender-runs

Prove a guard fires in the environment the offender runs in, not the one you are standing in. Worktrees, containers and per-scope config each get their own view of the setting a guard hangs on, so it can be armed where you test and absent where it matters. Reproduce the violation from the offender's own environment and watch it refused. A reference-transaction hook written for a 24-bead deletion passed its suite and a live probe in the main checkout while every dwarf worktree overrode core.hooksPath and ran without it. (sp-urifb, 2026-09-18)
