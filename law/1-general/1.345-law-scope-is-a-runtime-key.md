# §1.345 law-scope-is-a-runtime-key

What the fleet may work on is a runtime key, never a literal in the source. Scope, partition and repository selection belong in spira.conf with a default, so the operator changes what the system does without changing what it is. A fence built for a condition that has since ended is retired in the same change that ends it. Scar: every rune AND-ed on the literal `spira` to fence off retired Gas Town, so Spira could work on nothing but itself.
