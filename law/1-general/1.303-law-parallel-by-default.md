# §1.303 law-parallel-by-default

Run work in parallel by default. Serialise only on a resource you can name and have measured, and put the measurement next to the limit. A limit guessed from memory pressure sets the pace of the whole pipeline without anyone noticing. Scar: a batch width of 2 rested on an estimate that sixteen containers would exhaust 7 GiB; seventeen were measured in 2.5 GiB, and certification, attribution and landing had all been serialised on it.
