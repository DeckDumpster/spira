# §1.284 law-no-unsupported-language-releases

No repository runs on a language release its upstream no longer supports. For Rust that means the current stable, pinned to an exact version, because Rust supports nothing older. For Node and Python it means a release before its end-of-life date. Falling out of support is a defect: the repo gets a bump bead, filed by a detector rather than noticed by a person.
