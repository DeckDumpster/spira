# §1.394 law-write-only-inside-your-worktree

A branch's code writes inside its own worktree and nowhere else. It never rewrites a file the operator or a running process owns — a live config, an installed unit, a queue or run directory — and a tool that generates such a file takes an explicit output path and refuses the live one by default. Development runs on the operator's host; treat every path outside your worktree as someone else's production. Scar: two branches of one bead family rebuilt the live spira.toml three times, blinding the queue watcher (sp-hziou, 2026-09-26).
