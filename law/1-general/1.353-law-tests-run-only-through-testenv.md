# §1.353 law-tests-run-only-through-testenv

Suites run only through testenv, in a container; never on the host, whether from a worktree, the gate or by hand: a host run proves nothing about the candidate and can reach the real box. A unit test is not a suite: it calls no binary (law-a-unit-test-calls-no-binary), so builders and the submit check run it with cargo directly. (sp-kvq45a; a host suite run once set core.bare=true on production git.)
