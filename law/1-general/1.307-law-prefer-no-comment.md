# §1.307 law-prefer-no-comment

Prefer no comment. Put what a comment would say into a name, a guard or a test, where something runs it and something fails when it goes stale. Write one only for what the code genuinely cannot state, and keep it to a line or two. Scar: this repository's policy demanded long comments restating the mechanism, so three suites grepping for a mechanism matched the prose explaining it and passed against code the mechanism had been deleted from.
