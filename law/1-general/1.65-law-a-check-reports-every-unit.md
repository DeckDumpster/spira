# §1.65 law-a-check-reports-every-unit

An expensive check reports a verdict for every independent unit it ran, never only the first failure or a summary that discards the rest. One red must not hide the others: run every fence and suite to completion, name each red, and subtract what is also red on the base rather than stopping on it. Scar: 2026-10-08, 'base is red' collapsed every gate to one verdict all day, and member defects reached rounds unscreened.
