# §1.105 law-a-red-run-report-closes-on-its-fixes

A bead whose whole content is a report that a run was red closes as no-code-change as soon as every failure it names has its own fix bead, citing them in the close reason; it never waits for a later green run, and it never asks the operator for permission to close. Scar: five publish-red trackers for PRs 521-525 each escalated that same question on 2026-10-10, and the answer reached only one of them.
