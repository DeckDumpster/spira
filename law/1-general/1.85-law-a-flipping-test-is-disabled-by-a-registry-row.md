# §1.85 law-a-flipping-test-is-disabled-by-a-registry-row

A test that fails then passes on an unchanged tree is disabled in the same round by a test-registry row, for seven days, on a bead that fixes it or replaces it with a deterministic test; it is not retried. The round landing that bead runs the test on its merged tree first: green clears the row; red on the base keeps it, re-pointed at a new fix bead. A test red on both runs is a real defect. (sp-1xapjf; sp-bvbt7l: a cleared row turned main red.)
