# §1.151 law-an-eject-names-its-evidence

Never eject a round member on suspicion. The eject reason names what ties the red to that member: its diff, read and shown to reach the code the failing assertion exercises, or a green run without it. A diff audit suffices; a test run is not required. If neither ties it, keep every member and name the harness, the round or main as suspect. Scar: four wrong ejects on 2026-10-08.
