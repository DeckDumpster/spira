# §1.234 law-hand-over-in-four-stages

Hand a duty from a session to an automated actor one failure class at a time, in four stages: the session does it; the session does it AND positively confirms the actor would have done the same; the actor does it and the session confirms it was done properly; then the actor owns it, with telemetry left in place that detects whether it happened. Skip no stage, and record each class's stage where the next session can read it. Scar: the czar was armed for every queue class at once and had never handled one.
