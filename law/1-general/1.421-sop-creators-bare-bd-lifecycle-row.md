# §1.421 sop-creators-bare-bd-lifecycle-row

MATCH: Creators shell to bare bd.*lifecycle-row step
SYMPTOM: Static-read alarm that incident/gh-intake/groomer spawn plain bd (not bdq) so beads get no spira-lc create-bead row.
CHECK: grep -n 'lifecycle_row::after_create' incident/src/real.rs gh-intake/src/real.rs groomer/src/bd.rs  — all three hit; and spira-lc show <incident bead> is non-empty.
FIX: None needed: each creator calls spira_config::lifecycle_row::after_create itself right after bd create, so bdq's is_create hook is not required. SPIRA_BD resolves to the real ~/.local/bin/bd by design. Only a bead created by a NEW creator that lacks after_create would be rowless.
ESCALATE: If spira-lc show on a freshly created creator bead is {} — then file a bead naming that creator.
