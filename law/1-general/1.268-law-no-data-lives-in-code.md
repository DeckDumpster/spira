# §1.268 law-no-data-lives-in-code

In every dumpster, the dataset is the product and no data lives in code. When a source lacks what the product needs, build a remedial dataset — a data file in the repo, loaded by code, with its provenance beside it — never literals in source. Domain facts (set codes, names, categories, dates, rarities, prices) written into .rs/.py/.ts/.svelte are refused.
