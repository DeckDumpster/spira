# §1.500 sop-release-stale-renders-current

MATCH: STALE RELEASE: .* renders current, current is [0-9a-f]{40}
SYMPTOM: watchtower files release-stale incident whose "rendered" release is the literal word "current".
CHECK: grep SPIRA_RELEASE the unit file under ~/.config/systemd/user; if it ends in spira-releases/current and the unit file mtime is later than the current symlink, the unit is in force and the alarm is a false positive.
FIX: none on the unit. Probe bug in watchtower/src/probes.rs units_off_current (sha_of does not resolve the symlink); builder bead sp-trd8oy. Do not re-activate the release.
ESCALATE: if the rendered value is a real sha that differs from current, activate per the incident body.
