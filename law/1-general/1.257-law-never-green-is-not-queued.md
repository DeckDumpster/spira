# §1.257 law-never-green-is-not-queued

A PR that has never once passed CI is not queued work, it is unfinished work, and counting it
as progress is how a week disappears. Check the branch's own run history before treating it as
mergeable or blocked-on-merge: five of eleven pokedumpster PRs had never been green across
every run in three days, while the queue read as a throughput problem. Report never-green
separately from red-since-a-change; they need different fixes and only one of them is a queue.
