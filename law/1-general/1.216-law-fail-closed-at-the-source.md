# §1.216 law-fail-closed-at-the-source

Refuse an invalid value at the first place that can recognise it, loudly, naming the value and its source; never drop, clamp or default it with a warning for a later layer to notice. If existing data would now fail, sweep it in the same change. This binds a check that GATES an action: it fails closed. A check that only REPORTS may fail open, but must say in its output that it read nothing and why; decide which kind before writing the exit path. Scars: sp-4x1di; verify-asks.sh, ruled deliberate (sp-eyy9q, per Ryan 2026-09-24).
