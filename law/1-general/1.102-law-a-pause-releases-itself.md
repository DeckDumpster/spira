# §1.102 law-a-pause-releases-itself

A pause, drain or hold that a session or tool sets names its owner and its release condition, and lifts only on that condition or by an explicit act. Never because a clock ran out: a timeout with no event or barrier is a defect. Its time limit is a cap that pages the owner with what still holds it; a dead owner's pause is reported as orphaned, never silently lifted. Judge whether it is in force by its own record, never by the exit code of the command that set it.
