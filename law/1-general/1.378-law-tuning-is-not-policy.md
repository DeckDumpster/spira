# §1.378 law-tuning-is-not-policy

An operational setting — a concurrency, width, cap, timeout, interval or budget — is the Concierge's to change, never an escalation: change it, record the before-and-after measurement, and revert if the meter says so. 'Policy' means the declared desired state (what Spira is for, which work matters, which gates exist), not the knobs that tune how fast it gets there. A value Ryan once set is still a knob.
