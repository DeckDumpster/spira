# §1.381 law-units-build-what-they-exec

A systemd unit that execs a build artifact must build it before running it, or landing the source ships nothing. A gitignored binary does not travel with the code that produces it, so the port keeps serving whatever somebody last built by hand — Loom crash-looped 1249 times against a target/release that no one had built, repeating the cockpit panel's scar exactly. Rebuild when the source is newer than the binary, as the cockpit already does on a timer.
