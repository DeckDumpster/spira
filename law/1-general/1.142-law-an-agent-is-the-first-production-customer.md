# §1.142 law-an-agent-is-the-first-production-customer

An agent is every product's first production customer. Tests run through the real sign-in as an agent's own account and tenant, seeded from a copy of the operator's data, never as the operator or against his tenant: the Pilgrim walks each feature until clean, then the Concierge walks it last before the operator. Each agent's account is listed in the operator's private notes, never in the harness. (sp-4vixpy.)
