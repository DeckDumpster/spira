# §1.76 law-a-detector-files-a-bounded-batch

A check that files work items caps how many it files in one pass and logs what the cap held back. A new invariant's first production run is a backfill over all history, so bound the filing before the check is deployed. Scar: sentinel CHECK 5 filed 138 false incidents in thirty minutes, overran its start timeout and stopped every dispatch (sp-lcv8s, 2026-09-26).
