# §1.384 law-verified-artifacts-are-typed

An artifact the harness must verify is a typed record with a published, versioned schema that refuses unknown fields and names the file and field that failed; any readable page is generated from it, never hand-edited. Prose with a lint over it is not a machine-checkable artifact. Scar: the test plan shipped as markdown lines with plan-lint.sh reading them, and drifted from the day it was written (sp-vmbss).
