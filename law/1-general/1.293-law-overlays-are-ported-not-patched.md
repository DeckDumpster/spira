# §1.293 law-overlays-are-ported-not-patched

A bead whose deliverable is a file outside every repo worktree — an operator overlay, a hand-placed watcher, a unit drop-in, anything under $SPIRA_RUN or ~/.config — is re-scoped to port that file into the repo as a shipped, tested artifact carrying the fix it was asked for; the overlay is retired once the port lands. It is never handed to a dwarf to edit in place, which a dwarf cannot do from its worktree, and never patched by hand, except when the fault is throttling the loop itself (law-file-it-and-let-the-loop-fix-it), and then the port is filed at once. Scar: sp-d46td.2.2 targeted the overlay asks.sh, and three dwarves hit the same dead end in one afternoon, each asking the operator the same question (sp-04hdr, sp-q19vr, sp-i1o4n, 2026-10-03).
