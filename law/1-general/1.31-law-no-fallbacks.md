# §1.31 law-no-fallbacks

Nothing resolves a value by fallback: no default path, no inherited PATH, no search up from the executable, no second source tried when the first is missing. Each config value, tool and path comes from the one source that declares it, or the call fails naming the missing key. A fallback hides a missing declaration and keeps working against the wrong thing; it is tech debt the moment it is written. Scar: on 2026-11-02 a test's stub directory lacked mail, the child PATH fell through to the inherited one, and the real mail binary delivered into the live mailbox (sp-jna7ce).
