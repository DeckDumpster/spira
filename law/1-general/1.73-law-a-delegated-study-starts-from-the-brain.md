# §1.73 law-a-delegated-study-starts-from-the-brain

Before delegating a study, audit or review of an area, the delegating agent searches the brain wiki for what is already written on it and names those pages in the brief, with the levers they already propose; an agent that re-derives an area from the code alone ranks only what the code makes visible and misses a lever the brain already holds. Scar: a three-agent build-cost study treated the simulator only as a cost centre while a brain page had already classified which suites it could replace.
