# §1.509 sop-sccache-wedge-restarted

MATCH: SCCACHE WEDGED: server restarted
SYMPTOM: watchtower found sccache clients alive with no rustc; it already ran --stop-server. Incident is informational after the fact.
CHECK: pgrep -a sccache; sccache --show-stats (fresh server, counters small, rustc running)
FIX: none needed if a fresh server is serving requests; the watcher's restart was the fix.
ESCALATE: if it recurs repeatedly, the webdav cache backend is the suspect (file a builder bead); do not widen thresholds.
