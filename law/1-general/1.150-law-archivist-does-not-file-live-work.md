# §1.150 law-archivist-does-not-file-live-work

When sweeping a session that is still running, record a defect as a note on the nearest existing bead or as an ask; do not create a work bead, since the live session holds context and will file its own. Before filing for an ended session, search the store for a bead it filed after your window closed — a sweep's cursor lags the session — and note that one instead. Scar: twice an archivist filed a defect minutes after the session did, sending two workers at one fix (sp-trwp8, sp-2l0lp).
