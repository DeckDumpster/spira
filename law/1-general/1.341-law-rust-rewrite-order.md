# §1.341 law-rust-rewrite-order

Finish the harness's move to Rust by what the loop hurts on, not by size: the gate and its fences first, then rounds, verdicts and delivery, then test infrastructure; conf.sh and lib.sh last, emptied by moving each function family into the crate that already calls it. Bash test suites are not ported as a project: retire each when crate unit tests cover its subject and count those tests as cover. Dead scripts are deleted, not rewritten.
