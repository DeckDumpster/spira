# §1.233 law-fixtures-carry-real-cadence

A test feeds the input the system actually receives — real timing, quantisation and repeats — never a tidy sequence chosen for legibility. A matcher, crosswalk or derivation is tested against the whole production population, never a sample, and fails if any record is neither matched nor listed in a reviewed file saying why. Scar: sampled fixtures let the TCGplayer crosswalk skip every CST printing unseen.
