# §1.491 sop-reap-terminal-transient-exit2

MATCH: FAILED UNIT: spira-reap-terminal-prod\.service
SYMPTOM: reap-terminal-prod fails once (status=2/INVALIDARGUMENT after ~5s) while later hourly runs finish normally; the failed state lingers and the watcher recurs.
CHECK: journalctl --user -u spira-reap-terminal-prod.service -n 30 --no-pager  -- confirm a later "Finished" line follows the exit-2 failure.
FIX: none needed if later runs Finished; note the incident and close. If every run fails, diagnose the script's arg handling (exit 2) instead.
ESCALATE: repeated exit 2 on consecutive runs.
