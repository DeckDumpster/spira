# §1.190 law-declining-for-want-of-a-tool

A harness component that declines to act because a tool is missing must say so where a person reads it — a log line or a FAILURE, never a silent return and never a SKIP phrased as a fact about the machine. Name the tool and the PATH searched. Scar: conf.sh's PATH omits ~/.cargo/bin, so test-loom.sh skipped on every dwarf behind 'cargo not on PATH', Loom's own rebuild healer returned mute, and a worker learned to report the skip as expected.
