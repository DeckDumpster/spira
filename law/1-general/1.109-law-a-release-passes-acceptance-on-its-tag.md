# §1.109 law-a-release-passes-acceptance-on-its-tag

Never call a release clean, or hand it to another install, until end-to-end acceptance has passed on that exact tag. Acceptance means a fresh install, AND an upgrade from an aged, populated install (real database, config, mail and a live world) that keeps its state and lands one real bead, AND a rollback that restores the prior unit set or refuses safely. Green suites on main are not that evidence, because they stub the substrate. Scar: a second install six days behind rolled back every deploy (GitHub #109) while main was green.
