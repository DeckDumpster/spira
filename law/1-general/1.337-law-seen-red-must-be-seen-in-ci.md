# §1.337 law-seen-red-must-be-seen-in-ci

A test that asserts a bug REPRODUCES measures the machine as much as the code, so it is not
done until CI has run it green at least once. Reproduction usually needs state a fresh CI
workspace lacks — a primed build cache, an idle box, warm artifacts — and a developer's
machine has all three. Two pokedumpster PRs shipped SEEN-RED arms verified only locally,
never passed CI once, and blocked the queue for days: one needed a primed cargo cache, the
other a WAL ratio that collapses from 12x to 2.3x under suite load.
