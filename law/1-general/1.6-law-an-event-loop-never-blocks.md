# §1.6 law-an-event-loop-never-blocks

An event loop never blocks: every blocking call it would make, file, socket, process, lock or sleep, is dispatched through a bounded queue to a bounded thread pool, and the loop only awaits the result. A full queue refuses, logs and alarms; spilled work stays undone and is redriven adaptively, never dropped.
