# §1.424 sop-deploy-fault-duplicate-watcher-row

MATCH: watcher manifest is malformed.*is already defined above
SYMPTOM: LAND DEPLOY FAULT; release verify fails in pre-activate units-install --render because ~/.config/spira/watchers.d/*.watchers has a duplicate row name.
CHECK: release verify <sha> 2>&1 | grep 'already defined above'
FIX: remove the duplicate row from the named watchers file (operator-side overlay, not in repo); re-run release verify <sha>; then a non-aeon session runs release activate <sha> (aeon fence refuses it) which clears run/queue/<repo>/deploy-fault.
ESCALATE: activation is operator-only; if verify passes but the marker persists, ask operator to run release activate <sha>.
