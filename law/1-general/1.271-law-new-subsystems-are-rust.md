# §1.271 law-new-subsystems-are-rust

Write every new subsystem in Rust, including inside codebases written in another language, and inside the Spira harness itself. A subsystem is a new program, daemon or component with its own entry point, state or protocol, not an edit to an existing script. Existing bash may be extended, but a new capability does not start life as a new .sh file. This narrows law-rust-then-java's exemption for existing codebases. When in doubt whether it is new, it is (per Ryan, 2026-09-19).
