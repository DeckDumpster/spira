# §1.323 law-reproduce-acceptance-locally-before-remote

Where the only real run of a path is an expensive remote attempt — acceptance, a release, a CI round — reproduce the failure locally on a throwaway instance and show the fix green there on the exact tree before spending the attempt, for every phase. A remote run is a confirmation, never a probe. When a path cannot run locally, building that local path comes before the fix; run it as a pre-attempt gate, not in every round. Scar: five acceptance defects each found by its own ~40-minute release, all catchable locally in minutes.
