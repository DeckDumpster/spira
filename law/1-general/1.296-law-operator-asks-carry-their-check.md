# §1.296 law-operator-asks-carry-their-check

An ask that Ryan satisfies by running a command must carry the command that proves it done: a VERIFY line in the bead, read-only, exiting 0 once satisfied. verify-asks.sh runs them on a timer and closes what passes, with the output as evidence. A calendar-subscription ask sat in his queue three days while its own proving command already exited 0 — he had done it days earlier. Prefer a machine check over asking him twice.
