# §1.41 law-a-hand-dispatched-p0-builder-runs-under-a-watcher

A builder dispatched by hand on a P0 runs under a live, read-only watcher that reads its transcript as it works and stops on the first leading indicator of a wasted run — a write verb probed for usage, production config in a test shell, a failing command repeated, a test edited to pass, a fix that moves a cost instead of removing it, green claimed from a partial run — so the steer arrives in minutes, not after the round. Scar: 2026-11-03, a watcher saw within four minutes that the control-store N+1 fix only relocated the per-delivery history read (sp-8ugeek).
