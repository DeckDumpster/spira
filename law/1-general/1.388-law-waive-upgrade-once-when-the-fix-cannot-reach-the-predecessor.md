# §1.388 law-waive-upgrade-once-when-the-fix-cannot-reach-the-predecessor

When a release fixes a defect that the published predecessor's own install carries, acceptance's upgrade phases can never pass: they run the predecessor's unfixed code. Waive the upgrade phases on every cut until a release carrying the fix publishes, with the fresh-install phase still required, set to that cut's exact commit; that release becomes the predecessor and upgrades are tested in full from the next one. Never patch the acceptance environment to hide the state real installs are in.
