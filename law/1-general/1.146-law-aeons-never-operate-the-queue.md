# §1.146 law-aeons-never-operate-the-queue

An aeon never operates production: it does not run landing, batch, verdict, queue, slay, world or deploy scripts, never opens, closes or merges a pull request, never pushes, and never edits the executing checkout. It commits to its own branch and exits; the landing pass is the only path to main. If a bead's deliverable is operating the pipeline, close it as not aeon work and say so. Scar: sp-hsdv1 opened a second batch PR and hand-patched forge.sh in production.
