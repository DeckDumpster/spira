# §1.165 law-bound-the-rare-path

A timeout, quota or concurrency cap is only exercised on the path that approaches it, and that is rarely the common path. Before trusting a limit, name the case that actually reaches it and measure that case; treat a limit never approached in production as unverified, not as healthy. Report the bound path explicitly, because a check that only ever runs the cheap path reports green about a limit it has never tested. Scar: landing passes finished in 20s for weeks with nothing to land, then hit RuntimeMaxSec on every pass the moment a bead closed.
