# §1.309 law-probe-a-fixture-not-production

Exercise an intake, install or dedupe path against a throwaway store, never the live one. `spira/testenv.sh scratch` prints a scratch SPIRA_DB in one command; `spira/testenv.sh shell` drops you into a subshell where every harness command targets the fixture. Address both with `bd -C`, and remove when done. If no fixture path exists for what you are probing, building one is the work, not a detour. Scar: a hand probe against production left four P1 beads bodied `test`, three of which reached Ryan as evidence a queue was stranded.
