# §1.324 law-require-the-right-value

When a wrong or missing value keeps appearing at an interface, fix it by making the right value a required, obvious field of the facade that every caller goes through, with no default, so the easy path is the correct one; do not add a refusal that pattern-matches the wrong value downstream. Scar: bead titles kept carrying their repo because the repo field was not obvious, and a title-refusal added to fix it broke a harness filing path.
