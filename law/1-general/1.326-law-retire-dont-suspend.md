# §1.326 law-retire-dont-suspend

A subsystem nobody wants running is deleted, not suspended. A suspension is a record, and nothing guarantees every path that starts the thing reads it: an installer re-renders the unit, a timer re-arms, a manual start ignores the flag. Remove the unit, the code path and its tests, and make install remove it from boxes that have it. Scar: spira-suites was suspended on 2026-09-15 and ran hourly for ten days, failing and filing misdiagnosed incidents (sp-b99nj).
