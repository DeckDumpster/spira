# §1.149 law-an-agent-is-the-first-production-customer

An agent is every product's first production customer. Tests run through the real sign-in as an agent's own account and tenant, seeded from a copy of Ryan's data, never as Ryan or against his tenant: the Pilgrim (pilgrim@gantt.pub) walks each feature until clean, then the Concierge (concierge@gantt.pub) walks it last before Ryan.
