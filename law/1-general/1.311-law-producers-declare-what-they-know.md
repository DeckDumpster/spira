# §1.311 law-producers-declare-what-they-know

A producer that can derive a fact must declare it, never escalate it. Any script filing a bead — an incident, a suite failure, a sweep result — states the repository, the priority and the owner from its own position rather than asking Ryan; escalate only what no caller could know. An escalation path that can emit the same question twice is a defect in the path, not a queue to be drained. Scar: suites.sh omitted a repo it always knew, and 57 identical asks buried the decisions pane in a day.
