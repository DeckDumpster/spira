# §1.383 law-upgrade-window-is-seven-days

A release is clean only when upgrade acceptance passes from the previous tag and from every tag up to seven days older; older upgrade paths are reported, never blocking. Run the aged-install path with real state, not a clean slate: the goal is a viable upgrade, and a fresh install proves nothing about one. Ryan set the window on 2026-09-20 (sp-w1j40).
