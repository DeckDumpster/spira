# §1.185 law-converge-by-reconciliation-not-atomicity

Every invariant the system relies on is held by a reconciliation loop, not an atomic write. The loop observes actual state against the declared state on a schedule and takes one idempotent corrective step per pass, so a write that half-fails is repaired by the loop that notices it. A new mechanism that records state names the loop that converges it, or it is not done (the reconciler epic, sp-lkfto). Scar: an ask hold whose mail failed sat silent for four days.
