# §1.217 law-fence-loops-on-shared-hardware

Anything that polls in a loop on this box gets a systemd CPUQuota before it is enabled. A read-only convenience UI must never be able to starve production. Unbounded, gt dashboard held 14-34 concurrent bd processes against one dolt server, drove load past 60 on four cores with swap exhausted, and GitHub killed the self-hosted CI runner for lost communication — so branch protection blocked every pokedumpster merge for a day while the refinery escalated and waited. Cap it; do not trust it.
