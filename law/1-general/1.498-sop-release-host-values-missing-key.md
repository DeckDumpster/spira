# §1.498 sop-release-host-values-missing-key

MATCH: has placeholders nothing fills
SYMPTOM: release activation refuses a unit template with an unfilled @KEY@ placeholder; deploy fault marker on a landing
CHECK: grep -n "@KEY@" systemd/*.service; grep KEY release/src/config.rs (host_values) — key missing there but present in install/src/values.rs
FIX: insert the key in release/src/config.rs host_values (env, else spira_config default); re-run build/verify/activate. Test rendering all templates against host_values tracked in sp-qf5x9.
ESCALATE: if key has no sane default.
