# §1.113 law-a-remainder-is-not-a-cap

A number that already nets out what is running is a REMAINDER, not a cap. Never subtract the running count from it again. When one layer computes how many MORE may start and hands it to another, the second layer must use it whole; re-subtracting withholds more the more is running, so the system saturates at half its ceiling and reports itself at its limit. Name every budget in its variable as remaining or as ceiling. Scar: the governor was fixed for this in 2026, then rune_free shipped the identical fault eight lines below the comment describing it.
