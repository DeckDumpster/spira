# §1.227 law-functional-behaviour-is-tested-not-soaked

A change to functional behaviour is proven by a functional test that passes or fails now, never by leaving it running and judging it later. Something either works or it does not, and letting a broken thing run longer produces no information. A wait of the form 'let it run N hours, then judge' is legitimate only for a property that is itself a function of time or load: a rate, a latency distribution, a leak. For anything else, write the test, see it red, see it green, and close the control on that.
