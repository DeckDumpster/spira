# §1.305 law-periodic-tool-needs-a-tested-timer

A tool meant to run periodically is not done when the script works. Its acceptance criteria must include the timer registration itself: the unit installed, enabled, observed to have fired, and covered by a test that fails if the registration is removed. A header comment saying it runs on a timer is documentation of an intention, not a mechanism. Scar: moot-sweep.sh and verify-asks.sh both described themselves as running on a timer, both were tested, and neither had a unit or a cron entry — the only reference to either was a comment in ask.sh asserting the timer existed, so 73 escalations accumulated unswept (sp-qy8bf).
