# §1.227 law-file-less-than-you-land

Reversed on 2026-11-17 and no longer a limit on filing: read law-defects-are-filed-and-features-rank-first, which governs. A defect in the machine is filed when found; features the operator asked for rank first at priority 0. The earlier rule, that a day filing more beads than it lands is a failing day, is withdrawn (sp-f9eujh).
