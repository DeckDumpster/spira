# §1.38 law-text-only-changes-land-without-a-round

A change that touches only text — law/, statutes, wiki, docs, markdown — lands without a round: lint it on the host and land it with the lint as evidence. A round VM certifies compiled code and suites; it can certify nothing about text that lint cannot, so every minute a text bead spends as a round member is a minute of pure cost, and every co-member's red delays it for nothing.
