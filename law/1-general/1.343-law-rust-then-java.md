# §1.343 law-rust-then-java

For new side-project code, default to Rust; Java is the fallback where JVM ecosystem integration is genuinely required. Do not reach for Python or Go without an explicit reason. Lead with the Rust ecosystem option: clap for CLIs, tokio for async, axum or actix-web for servers, sqlx or diesel for SQL. This does not apply to work-context discussions, to existing codebases already written in another language, or to wiki and planning content.
