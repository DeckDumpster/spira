# §1.143 law-address-the-store-with-spira-bd

Address a production beads store with $SPIRA_BD and name it by absolute path, bd -C "$SPIRA_DB", never by discovery from the working directory or $HOME: a stray .beads there is a shadow store that answers confidently. Inside an aeon or fixture, bare bd can be a tempdir symlink to an older release that reports a healthy store broken while exiting 0; print type -a bd before reporting any store broken. Scars: five aeons escalated a rollback of 3,296 healthy beads; three sessions spent ~30 turns rediscovering the store while $HOME/.beads pointed at the test port (sp-u1l5y, 2026-09-27).
