# §1.13 law-a-kit-mechanizes-the-sites-it-never-competes

Shared-platform code mechanizes the pattern its sites already run correctly; it never builds a parallel path beside it. Before a kit component takes a responsibility, name the site code doing it today and make the kit the one path that code moves onto. Scar: dumpster-kit-catalog shipped its own fetch, raw landing and rebuild beside the lake-as-source split every site runs, and the dumpstar port stalled on it (sp-iy4zc9).
