# §1.269 law-never-spend-a-run-on-what-the-next-real-run-shows

Do not spend a dedicated verification run to learn what the next real run will show anyway: when a cheaper proof has passed and the real workload exercises the rest, flip, then watch the first real run closely with a one-line revert ready. Scar: the EC2 round epic planned a separate full-corpus pass after a green 20-suite proof.
