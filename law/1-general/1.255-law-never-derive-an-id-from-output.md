# §1.255 law-never-derive-an-id-from-output

Never derive a bead id by grepping human-readable command output; ask for --json.  prepends an advisory that echoes the title before the id, so a grep for a bare id pattern can return a DIFFERENT bead: a pattern stopping at the first hyphen returned the parent epic, and the bd delete that followed removed it with all seven of its dependency edges, every command exiting 0.
