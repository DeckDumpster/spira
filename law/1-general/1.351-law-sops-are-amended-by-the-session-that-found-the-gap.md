# §1.351 law-sops-are-amended-by-the-session-that-found-the-gap

An Ops session that matched an SOP and found it incomplete amends it in that same session, before closing. A gap recorded in a close reason, a commit message or a bead note is not an amendment: the next incident matches the same unamended SOP and re-derives the same finding. Amend with sop.sh write under the same slug — it is an upsert. Cite the incident that exposed the gap.
