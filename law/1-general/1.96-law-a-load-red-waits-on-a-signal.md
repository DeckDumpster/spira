# §1.96 law-a-load-red-waits-on-a-signal

A test red only under the full-corpus run and green at low load is repaired by waiting on a signal the code under test emits, with a generous cap, never by widening a timing window; where no signal exists, the code gains one or the case is deleted. One widening is allowed as a load allowance written beside the constant with the corpus width it was tuned for; a second widening of the same window is a defect, filed as one (sp-a23dj, 2026-09-26).
