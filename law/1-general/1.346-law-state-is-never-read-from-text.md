# §1.346 law-state-is-never-read-from-text

Decide any object's state or status — bead, round, batch, hold, ask, unit, release, mail — only from a typed value: an in-process typed API, a command's JSON answer deserialised into a struct, or an exit code mapped to an enum. Never from text: no regex, substring, split or line-parse of output, no identity cut from a unit name, no 'cannot tell' substring. (sp-druc64, sp-bpnmzg: parsed holds and unit names stranded beads and broke the fleet ceiling)
