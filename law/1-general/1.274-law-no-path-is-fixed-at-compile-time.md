# §1.274 law-no-path-is-fixed-at-compile-time

No absolute path makes it into compiled code: relative paths only, resolved at run time from the process's own environment through the one door (SPIRA_HOME, the testkit and spira-config doors), and a fixture gets no exception. The lint refuses env!("CARGO_MANIFEST_DIR") and its kin and an absolute path literal. Compiled-in content (include_str!, a build script's output) is not a path. (sp-duiwl1, sp-j9i7qe; scar: a gate reusing its builder's build ran tests against the builder's worktree, three false reds in five minutes, and sim-replay shipped reading its build tree.)
