# §1.440 sop-fence-gate-fixture-missing-retired-key

MATCH: FENCE gate: RED.*gate fixture-config: .*complete\.toml does not resolve against the landing ref.*is not declared
SYMPTOM: Round dies in the fences phase before any suite runs. The fixture-config fence says the round branch's spira/testlib/complete.toml lacks a key the landing ref (origin/base) still requires.
CHECK: git show <round-branch>:spira/testlib/complete.toml | grep -c <key>  (0 = confirmed), then git merge-base --is-ancestor dc1de3b53 local/main (the sp-nao9lu commit that put runtime_repo_events_secs back in the fixture).
FIX: If local/main's fixture declares the key, nothing to fix: the round was cut from a branch that predates the restoring commit. Re-cut the round on current local/main. If local/main also lacks the key, file a builder bead to restore it in complete.toml and spira.toml until the active release stops reading it. Do not retire a key from the fixture before the landing ref retires it.
ESCALATE: Not needed unless two consecutive fresh rounds hit the same fence.
