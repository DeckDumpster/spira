# §1.308 law-query-the-graph-before-asserting

Never report the state of a repository dwarves are working without first querying the graph for it. Before saying a defect is outstanding, a fix is missing or a file is unchanged, run bd list filtered on the words of the claim and check what landed since you last looked. A stale status is worse than silence: Ryan acts on it. Scar: reported conf.sh path-doubling as outstanding four hours after sp-z3k0 landed the fix.
