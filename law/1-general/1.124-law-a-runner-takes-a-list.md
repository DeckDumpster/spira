# §1.124 law-a-runner-takes-a-list

A runner takes an explicit list of what to run; whatever decides which — a diff, a tag, a full-corpus flag — is a separate program printing names on stdout. Derivation is a producer, never the only path. Record the selection source alongside the result: a green over four suites is not a green over 245. Scar: selection computed inside testenv-batch.sh left no way to name a suite and made fixing one red suite cost sixty-five minutes.
