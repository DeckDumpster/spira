# §1.383 law-workers-verify-with-container-tests

Prod is off limits; the repo's own container test tooling is not. Verify with the tiered runners the repo ships rather than cargo or unit tests alone — pokedumpster has .claude/skills/run-tests (cargo, lint, frontend, ci, ui, full), qa-finish and fix-ci. Spin up your own named instance; instances are isolated by name and any name except prod is safe, so clean up what you create. Verification may instead be left to a dedicated validation step at the end. What is not acceptable is silently degrading verification to fast unit tests.
