# §1.273 law-no-horizontal-scroll-on-mobile

No page on any site scrolls horizontally on a phone: rows of chips, tiles, titles and controls wrap, and every route is checked at phone width in each site's UI tier. A sibling site that already wraps is the reference for the one that does not. Scar: /browse jump-to chips, set tiles and section titles ran off-screen on dumpstar and pokedumpster.
