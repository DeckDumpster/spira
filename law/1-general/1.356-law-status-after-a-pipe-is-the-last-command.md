# §1.356 law-status-after-a-pipe-is-the-last-command

The exit status after a pipeline belongs to the LAST command in it, so reading it after piping into head, tail, grep or sed reports the pager's status and never the program's. Capture the output first and read the status of the bare command, or address PIPESTATUS explicitly. A check that reports success it did not measure is worse than no check. Scar: a gate run piped into tail reported rc=0 while the landing gate was red, and the whole repository stayed unlandable (sp-98f8, 2026-09-08).
