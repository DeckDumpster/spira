# §1.160 law-buy-capacity-rather-than-wait

Buy capacity rather than wait, and only when actually waiting: a test run (a landing round or a provisioned CI job of any registered repo) goes to a Proxmox VM first and spills to EC2 only when no local VM is available within the spill wait or the host is under I/O pressure; placement is round_vm_spill = ec2 for rounds and spill: ec2 for CI. Paying for EC2 while the local hypervisor sits idle is waste, not speed. Scar: ruled four times toward EC2 after a publish run took 31.5 min on the loaded host (2026-10-15), then amended when EC2-always rounds' EBS volume-initialization fees reached $15/day with Proxmox idle.
