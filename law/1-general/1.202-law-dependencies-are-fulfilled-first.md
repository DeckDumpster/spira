# §1.202 law-dependencies-are-fulfilled-first

Dependencies are resolved and verified first: every CI job and local check verifies every dependency of the tiers it will run before any build or test, and fails within two minutes naming what is missing. A test that discovers a missing tool mid-run is a preflight defect. Scar: dumpstar PR 77 spent 49 minutes on an EC2 VM before finding PyJWT absent (per Ryan 2026-10-15).
