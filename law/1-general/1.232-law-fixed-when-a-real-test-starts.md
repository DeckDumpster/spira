# §1.232 law-fixed-when-a-real-test-starts

A fix to a shared execution path (a runner, an image, a template, a provisioning script) is proven immediately after the build that carries it, by driving the smallest real workload down that path until a real test has started on it; it need not finish. Until then the fix is unproven, whatever a smoke check or a unit test says. Scar: three EC2 spill fixes in one day were each found broken only when a real job happened to spill hours later.
