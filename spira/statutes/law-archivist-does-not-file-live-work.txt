When sweeping a session that is still running, record a defect as a note on the nearest existing bead or as an ask — do not create a new work bead for it. A sweep triggers on turn count, not session end; the active session holds context and will file its own work. A pass that filed a defect ninety seconds before the live session filed it sent two aeons to fix one line on two branches. File work only for sessions that have ended.
