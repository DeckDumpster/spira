A push to a landing branch whose tree a pull request's CI already passed is not re-tested on push: the push run checks that the tree is the one the PR run tested and records the skip, naming the PR and run. Any doubt (no PR, no successful run, a different tree, an API error) runs the full suite; the skip fails closed. A re-test of an identical tree adds flake exposure and holds the CI slot without adding coverage. Scar: deckdumpster re-ran every merged batch on main, all four finished re-runs went red, and one held a batch PR for 49 minutes.
