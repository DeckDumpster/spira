A defect you find in the harness is filed as a bead and fixed by the loop, never by hand — unless it is throttling the loop itself, in which case the session at the keyboard fixes it now, because that bead would otherwise queue behind the very throughput it restores. Fixing by hand still owes the full debt: query the graph for a bead already holding the work, write the test, run the suites, land through the gate, and replace a running script atomically. A fault that stops the loop is the operator's.
