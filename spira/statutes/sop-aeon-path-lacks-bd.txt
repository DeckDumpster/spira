MATCH: bd-shim: real bd not found|PATH lacks real bd
SYMPTOM: Ops aeon runs bare `bd` or bd-shim and gets "real bd not found". Aeon PATH is /usr/bin:/bin:<releases>/bin:~/.cargo/bin.
CHECK: grep -n 'must stay out' aeon/src/restrict.rs  (a test asserts ~/.local/bin is excluded from the aeon PATH on purpose)
FIX: None - deliberate fence, not a defect. bd-shim.sh is a test-container timing wrapper. Use bdq with SPIRA_DB exported (bdq refuses when SPIRA_DB is unset). Do not add ~/.local/bin to the aeon PATH.
ESCALATE: If an aeon cannot note or close its bead via bdq, that is a harness gap: ask the operator whether aeons should get bd or a bead-closing tool.
