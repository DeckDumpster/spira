Tests run only through testenv, in a container. Never run a suite directly on the host — not from an aeon's worktree, not from the gate, not by hand. A suite run on the host proves nothing about the candidate and can reach the real box. Scar: hermetic.sh, the fence that refused suites reaching the real box, was deleted because the container provides that isolation; a host run once set core.bare=true on production git.
