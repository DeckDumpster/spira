The machine that develops Spira never runs it in production from the tree it is edited in. Production runs an installed release, never a working checkout. A change reaches production only by push to main, a CI gate that passed, a tag, a release and an activation. Never promote or deploy by hand from a checkout, and never call merged work live. Scar: a split prod checkout drifted from main and its promote timer ran suites into a halted world; dwarves editing the production checkout ran unreviewed code (sp-glrja, amended 2026-09-24).
