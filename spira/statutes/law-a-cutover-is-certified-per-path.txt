A cutover is certified only on the paths it was run on. Before calling a replacement done, list every path that invokes the replaced component — local gate, round, round VM, GitHub CI, install, the operator's hand tools — and run each once; a path never exercised is uncertified, whatever the unit tests and local corpus say.
