When one repository, database or path is split in two, every variable naming the old shared location goes on resolving and starts meaning the wrong thing. Grep every consumer of that name and repoint each deliberately — a tool that still runs is not evidence it was reached. For a tool that ships inside the thing it operates on, self-locate rather than take a configured path, and refuse a path that fails a cheap identity check. Scar: BRAIN=$SPIRA_REPO survived the harness split in four brain tools; the JSONL mirror wrote to the wrong repository and exited 0 for eight hours. (sp-mt8x)
