Ask whether the work is needed before acquiring the resource that would do it. A selector, diff or predicate costing milliseconds runs before the VM, container or lock that executes its answer, and must be able to skip the acquisition entirely. Scar: gate.yml provisions a 12 GiB runner unconditionally, so a one-line text file that selected zero suites waited 54 minutes for a machine it never needed; the landing pass ran a serialised local gate before opening a pull request whose own CI was the authority.
