A tmux server hands every new pane the environment it was forked with, frozen for the server's life. Never start one from inside an agent session without clearing that session's identity first, and scrub an existing server before relying on it. Scar: rebuild.sh run inside an aeon gave the cockpit server CLAUDE_CODE_CHILD_SESSION=1, so the operator's own session — opened in a pane hours later — silently stopped writing a transcript and vanished from the context meter. Use cockpit/tmux-env.sh.
