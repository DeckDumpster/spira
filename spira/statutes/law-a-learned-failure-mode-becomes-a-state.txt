When a failure mode is understood, model it in the lifecycle: add the state, the event and the valid transitions that name it, so the machine records it, refuses what it makes illegal, and every view can show it. Do not hide it in a timer, a log line or a convention, and do not answer it with another gate in front of the work: more states make the system predictable; more gatekeeping makes it slower.
