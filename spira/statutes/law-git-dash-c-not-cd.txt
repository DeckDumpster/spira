Always address git by repo path — 'git -C <repo> add/commit/push' — never rely on the working directory. A cd earlier in the same command or turn persists, so a later 'git add -A' sweeps whatever repo you happen to be standing in: twice in one session that put brain-repo commit messages onto unrelated Gas Town state, and a wrong message is worse than a wrong file because it is what the next reader believes. Verify with 'git -C <repo> log --oneline -1' before moving on. (2026-09-01)
