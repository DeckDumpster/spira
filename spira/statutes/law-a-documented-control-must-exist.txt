Never write a document that asserts a control no program enforces. A header comment, README or bead brief naming a test, path or mechanism is read as proof it exists, and every reader downstream stops checking. Before writing such a sentence, run what it names; on finding one already written, restore the control or delete the claim. Three landed in one day — eight brief commands under a path deleted at the split, and a repo test suite cited twice and never written. (sp-9tmj)
