Commit only the paths you changed. In a checkout other sessions and aeons write concurrently, git add -A and git commit -a sweep up their staged and unstaged work, so your commit message describes a fraction of its own diff and their edits land unreviewed under your subject; the rebase that follows then conflicts in a file you never opened. Name every path on the git add line, and re-read git show --stat before pushing. A statute commit once carried two other sessions files and conflicted on rebase.
