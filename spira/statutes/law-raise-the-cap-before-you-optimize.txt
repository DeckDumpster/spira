When a resource cap (a VM's memory, a runner's size, an instance type, a concurrency limit) blocks a path that has never yet run end to end, raise the cap to whatever makes the path run and file the reduction as separate later work; do not make the consumer leaner first. Record the raise with its revert and state the target the reduction must reach.
