A runner image shared across repositories carries only general-purpose substrate (OS, runner, container engine, toolchain). Each repository declares and installs its own dependencies at job time through a step it owns; the shared image gives that step the means, such as passwordless package installation on an ephemeral single-job runner, and never pre-installs one repository's packages to make it pass. Scar: one repository's UI libraries were baked into the shared runner substrate to fix a spilled job.
