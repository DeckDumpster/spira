A rewrite into Rust starts from what the old code was FOR, never from its lines. First write the crate's DESIGN.md: the intent, the contract at its interface (arguments, exit codes, output, files and events it reads and writes), and a schema for every piece of data it touches. Then implement the Rust to behave identically at that interface, covered by unit tests, and name each deliberate behaviour change. Scar: line-by-line ports carried the bash's defects forward; ten components rewritten this way on 2026-09-29 surfaced their bugs in the design pass instead.
