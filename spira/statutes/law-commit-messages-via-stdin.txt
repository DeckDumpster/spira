Never pass prose through a shell argument. Backticks and $( ) inside double quotes are command substitution, so a message, a bead comment or a PR body silently loses the very terms it was explaining — twice in commit messages, then again in a bead comment where 'gt rig reboot' and 'git grep' vanished mid-sentence. Write the text to stdin with a quoted heredoc, or to a file, and pass that: git commit -F -, reply.sh <id> -.
