The production checkout is a deploy artifact, never a working tree. Nothing commits or edits there; commit in your own worktree. A promotion salvages and resets whatever drift it finds before doing anything else, checks the exit code of every write, then re-reads HEAD and the tree to confirm the move actually happened. Announce a promotion only from what the tree says, never from the fact that a command ran. Scar: an aeon's commit froze nineteen landings for four hours while every pass logged success.
